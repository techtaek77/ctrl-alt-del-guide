# Ctrl+Alt+Del은 왜 세 개나 눌러야 할까?

1981년 IBM PC 개발실의 재부팅 단축키가 윈도우 로그인 보안 키가 된 과정을 벨로키와 키보드 실험으로 설명하는 TECHTAEK 교육 자료.

- 공개 페이지: https://techtaek77.github.io/ctrl-alt-del-guide/
- index.html 하나에 벨로키 이미지와 1981년 키보드 실험을 포함한다.
- 키보드 실험은 실제 IBM PC 83키 배열을 단순화한 교육용 모델이며 실제 키 간격과 다를 수 있다.
- 벨로키 삽화는 AI 생성 TECHTAEK 캐릭터 그림이다. images/ 폴더는 블로그 본문용 사본이다.
